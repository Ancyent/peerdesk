A — Wizard pas cu pas

Configurare → alege platforma → instrucțiuni de instalare. Ghidează utilizatorul complet. Ideal pentru utilizatori mai puțin tehnici.

⬇️ Instalare Agent

Alege platforma și copiază comanda de instalare:

curl -fsSL https://peerdesk.io/install.sh | \
  PEERDESK_PASSWORD=abc123 \
  SIGNALING_URL=wss://srv.io/ws \
  bash

B — One-liner + download direct

Selectezi platforma, copiezi o comandă cu totul pre-configurat (parolă, URL server). Download binar dacă preferi. Rapid pentru tehnicieni.

⬇️ Adaugă Mașinărie

Generează un token de înregistrare și rulează agentul pe mașina dorită:

A3F9-K2PX
Valid 24h · folosit o singură dată
peerdesk-agent --token A3F9-K2PX \
  --server wss://srv.io/ws

Mașinăria apare automat în dashboard după conectare.

C — Token de înregistrare

Generezi un cod scurt (ex: A3F9-K2PX), valid 24h, folosit o singură dată. Agentul se auto-înregistrează la prima pornire. Simplu și sigur.

Poți combina — de ex. B + C. Spune-mi în terminal ce preferi.
